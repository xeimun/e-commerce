# 성능 측정 및 개선 리포트

이 문서는 실제 성능 측정 결과, 병목 가설, 개선 내용, 재측정 결과를 기록한다. 성능 개선 후보와 우선순위는 `docs/performance/plan.md`에서 관리한다.

## 기록 원칙

- 측정 결과는 수치와 해석을 함께 기록한다.
- 개선 전후 조건이 다르면 직접 비교하지 않는다.
- 정합성 기준과 성능 기준을 분리해 기록한다.
- 로컬 측정 결과는 운영 성능 보장이 아니라 같은 조건에서의 상대 비교 근거로 사용한다.
- 면접에서 설명 가능한 성과 문장을 함께 남긴다.

## 성능 개선 기록 형식

각 성능 개선 결과는 아래 항목을 기준으로 기록한다.

```markdown
### 성능 개선 제목

#### 상황

어떤 사용자 또는 운영 상황을 재현했는지 적는다.

#### 문제

어떤 병목, 정합성 위험, 지연 요인이 있었는지 적는다.

#### 중심 CS 개념

이번 개선의 중심이 되는 CS 개념 1개를 적는다.

#### 보조 개념

결과 해석에 필요한 보조 개념만 적는다.

#### 기준 측정

개선 전 환경, 데이터 조건, 부하 조건, 측정 도구, 결과 수치를 적는다.

#### 병목 가설

측정 결과를 바탕으로 원인을 추정한다.

#### 개선 내용

무엇을 왜 바꿨는지 적는다.

#### 재측정

개선 후 같은 조건의 결과 수치를 적는다.

#### 결과 해석

개선된 지표, 악화된 지표, 변화가 없는 지표를 해석한다.

#### 정합성 검증

데이터 무결성과 비즈니스 규칙이 유지됐는지 확인한다.

#### 한계

로컬 환경, 데이터 규모, 테스트 방식의 한계를 적는다.

#### 다음 방향

다음에 검증할 병목이나 개선 후보를 적는다.

#### 면접용 요약

성과를 1~2문장으로 정리한다.
```
